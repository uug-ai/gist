Terminal and API

Share from the command line with curl, or script gist.uug.ai with its JSON API. Every gist is secret: only people with its link can see it.

From your terminal Edit key JSON API

From your terminal

Share a file

curl -T main.go {{.Base}}

Prints the gist's link. The filename picks the highlighting.

Share command output

make test 2>&1 |
  curl -T - "{{.Base}}/?filename=test.log"

-T - reads standard input; filename names the file.

Several files, a description and an expiry

curl -F file=@main.go -F file=@go.mod \
     -F description="Repro for #42" \
     -F expires=1w {{.Base}}

expires: 1h, 1d, 1w or 30d; leave it out to keep the gist.

Read a gist

# a single-file gist
curl {{.Base}}/<id>
# one file of a gist
curl {{.Base}}/<id>/raw/main.go
# every file, as a ZIP
curl -O {{.Base}}/<id>/archive.zip

Edit key

Whoever creates a gist gets its edit key: it is needed to change or delete the gist. Browsers keep it in a cookie for that gist. From a terminal, it's in the Gist-Edit-Key response header:

curl -i -T main.go {{.Base}}
# HTTP/2 201
# gist-edit-key: 3u1V…
# location: {{.Base}}/<id>

Keep the key private: anyone with it can change the gist. Send it as Authorization: Bearer <key>, or enter it on the gist's page under Enter its edit key.

JSON API

Shaped like GitHub's gist API: files is an object keyed by filename.

RequestWhat it does
POST /api/v1/gistsCreate a gist. The response includes edit_key.
GET /api/v1/gists/<id>Read the latest revision, with file contents.
PATCH /api/v1/gists/<id>Change the description or files: a new revision. Needs the edit key.
DELETE /api/v1/gists/<id>Delete the gist and all its revisions. Needs the edit key.

Create

curl {{.Base}}/api/v1/gists \
  -d '{
  "description": "Hello",
  "expires_in": "1d",
  "files": {
    "hello.py": {"content": "print(\"hi\")"}
  }
}'

Edit: change, rename and delete files

curl -X PATCH {{.Base}}/api/v1/gists/<id> \
  -H "Authorization: Bearer <key>" \
  -d '{
  "files": {
    "hello.py": {"content": "print(\"hello\")"},
    "old.txt":  {"filename": "new.txt"},
    "gone.txt": null
  }
}'

Delete

curl -X DELETE {{.Base}}/api/v1/gists/<id> \
  -H "Authorization: Bearer <key>"

Limits

  • Up to {{.Form.MaxFiles}} files and {{.Form.MaxSize}} per revision, UTF-8 text only.
  • A limited number of changes per minute per client; too many get 429.
  • GitHub's "public": true is refused: every gist is secret.
