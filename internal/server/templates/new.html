    From your terminal

    Share a file

    Share command output

    make test 2>&1 | curl -T - "{{$.Base}}/?filename=test.log"

    Several files, public, with a description

    curl -F file=@main.go -F file=@go.mod -F public=true \
     -F description="Repro for #42" -F expires=1w {{$.Base}}

    JSON API

    curl {{$.Base}}/api/v1/gists -d '{
  "description": "Hello",
  "public": false,
  "files": {"hello.py": {"content": "print(\"hi\")"}}
}'

    Gists are secret unless you add public=true ("public": true in JSON). Terminal uploads print the gist's URL. The Gist-Edit-Key response header (curl -i), or edit_key in JSON, lets you change it later with PATCH or DELETE /api/v1/gists/<id> and Authorization: Bearer <key>. curl {{$.Base}}/<id> prints a single-file gist.
